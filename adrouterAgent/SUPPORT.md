# Support

Use [GitHub Discussions](https://github.com/adrouter/adrouterAgent/discussions)
for setup and usage questions, and
[GitHub Issues](https://github.com/adrouter/adrouterAgent/issues) for
reproducible bugs.

Before opening an issue, run:

```bash
adrouter-agent doctor --json
```

Remove local paths or private information before sharing the output. Include
the AdRouter Agent version, macOS version, CPU architecture, whether the app
was installed from npm, the output of `adrouter-agent doctor --json`, and
concise reproduction steps. Never post
router tokens, provider keys, private source code, certificates, or npm tokens.

For security-sensitive problems, use the private reporting flow described in
`SECURITY.md`.
